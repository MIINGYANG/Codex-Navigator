# Web 设计预选

2026-09-06：用户已明确选择 **B — 专注阅读**，正式实现计划见 [Web v1.2.0](web-implementation.md)。以下保留设计阶段记录，三套样稿仍为合成预览，不连接真实会话。

目标：为本机 Codex 用户提供只读会话浏览器。页面的核心任务是找到主会话、回到某个问题、看清最终回复；不是统计仪表盘，也不承担发送 Prompt 或判断答案正确的任务。

本轮只交付 HTML 交互样稿。全部数据为合成；不读取 ~/.codex，不实现 --web，不连接云端或字体 CDN。用户选定后再正式实现。

## 三个方向

### A — 清晰工作台

- 色彩：纸白 #FFFFFF、冷灰 #F3F6FA、墨蓝 #18283D、钴蓝 #3568D4、雾蓝 #E8EFFC、琥珀 #A76520。
- 字体：标题 Trebuchet MS / 系统无衬线；正文 Noto Sans CJK SC / 系统无衬线；工具与时间使用 DejaVu Sans Mono。
- 布局：主会话窄栏 + 时间线中栏 + 留白正文。签名元素是贯穿时间线的选中蓝色轨迹，与正文轮次标识对应，表达当前阅读位置。

```text
会话 | 时间线 | Prompt → 活动 → 最终回复
```

### B — 专注阅读

- 色彩：淡紫白 #F8F7FC、白 #FFFFFF、深紫灰 #302A43、鸢尾 #7156AB、浅紫 #EDE7F7、棕金 #916A32。
- 字体：标题/阅读强调 Noto Serif CJK SC / Georgia；正文 Noto Sans CJK SC；时间与命令使用 DejaVu Sans Mono。
- 布局：轻量会话入口、单一宽阅读面、紧凑轮次目录。签名元素是当前问题与最终结论的阅读书签；工具活动退居折叠区域。

```text
会话入口 / 搜索
轮次目录 | 宽阅读面（问题、结论）
```

### C — 紧凑控制台

- 色彩：深板蓝 #17212D、深灰蓝 #202D3B、边线 #344454、冰白 #E8EEF6、湖蓝 #68B9D7、柔琥珀 #DCAD69。
- 字体：标题/数据使用 DejaVu Sans Mono；正文 Noto Sans CJK SC / 系统无衬线。
- 布局：紧凑项目/会话导航、横向轮次定位条和双区阅读器。签名元素是可跳转的轮次刻度，保留高密度但不过度模拟终端。

```text
项目 / 会话 | 轮次刻度 ─────────
            | 问题与结论 | 活动
```

## 设计自审

三套共享相同信息语义，但改变信息优先级和阅读路径。避免把它们做成同布局的三种皮肤：A 强调并列定位，B 强调长文，C 强调紧凑操作。无需营销头图、统计卡片墙或无意义动画；仅用清晰选中态、焦点和滚动定位反馈。

交互样稿覆盖主会话列表、会话/Prompt 搜索、轮次选择、f 最终回复、g/G 正文边界、活动折叠、返回会话及移动端导航。复制、模拟新消息等行为只针对合成样稿；任何模拟状态必须明确标记。预览不等于完整 Web 产品，正式版的数据层、安全边界和 --web CLI 在选定后推进。
