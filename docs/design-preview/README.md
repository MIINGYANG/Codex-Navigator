# Web 设计预览

这是待选择的 HTML 交互样稿，不是正式 Web 版。现有 binary 仍为 v1.1.2，尚无 `codex-nav --web`。

## 打开

在仓库目录运行：

```bash
python3 -m http.server 8877 --bind 127.0.0.1 --directory docs/design-preview
```

浏览器打开 http://127.0.0.1:8877/ 。服务仅绑定本机，仅提供这个设计目录；不提供仓库其他文件或 Codex 数据。停止预览服务用 Ctrl+C。

也可直接打开 index.html，无需构建或联网；浏览器在 file 模式可能限制复制功能。

## 如何比较

- 顶部 A/B/C 切换三种布局；“会话入口 / 阅读界面”查看两种页面。
- A 清晰工作台：浅色三栏，跨会话、轮次和正文的并列定位；含明确标记的模拟追加功能。
- B 专注阅读：轻量轮次目录、宽正文、克制书签视觉，长回复优先。
- C 紧凑控制台：深色、横向轮次刻度、正文与活动双区，强调操作密度。
- 页面支持会话选择、搜索、轮次跳转、f 最终回复、g/G 首尾、活动折叠和帮助。窄屏会改变布局。
- “标记方案”只在当前浏览器保存设计偏好并显示提示，不会通知 agent 或启动开发。请在对话中确认 A/B/C，或说明希望组合哪些细节。

全部会话、回复、命令和状态为合成数据。没有真实文件监控、跨进程通知、服务 API、鉴权或真实日志恢复。复制只复制样稿文本，失败会提示手动复制。正式的数据层、安全处理、功能完整性和性能验收将在用户选定设计后推进。

## 验收

按 web-access 技能启动 CDP Proxy，在本地 gallery 专用测试 tab 上执行：

```bash
node scripts/design_preview_qa.mjs PREVIEW_TARGET_ID
```

验收仅操作指定本地 tab：四份 HTML 的 JS 语法/外部依赖检查，三套设计桌面和手机宽度下的选择、搜索、f、g/G、折叠、帮助、返回及横向溢出检查。不会操作其他浏览器页面或接入真实会话。
