# 开发经验

## 2026-09-09 — 新网页应接替已有入口而非并列增加产品入口

- 用户纠正：不需要旧网页阅读模式，新问题画布应通过codex-nav --web进入，并支持深色主题。
- 修正原则：默认对外只讲终端/网页两种模式，旧codex-trail保留兼容但不要求用户记更多命令。接替入口必须同时处理--session、--no-watch、数据目录与刷新语义，不能仅重定向HTML。
- 后续检查：深色必须检查真正绘制像素的SVG层和图组件默认变量，外壳背景正确不等于画布正确；主题持久化保存在同源localStorage，随机端口不能承诺跨地址共享。用户说设计不推送时精确停止跟踪并保留本地，不能擅自重写发布历史。

## 2026-09-08 — 规格与参考图分别约束行为和视觉

- 用户明确新规格是行为与架构的依据，参考图是视觉依据，不能拿旧版横向轨道替代真实画布，也不能照抄图片中的登录、收藏或虚构问题分支。
- 实施时先完整读规格与参考图，再复用已验证的只读核心；以真实关系重现蓝白卡片的设计语言。线性数据应以可读布局呈现，不为了长得像树而发明父子关系。
- 验证需要真正浏览器：普通对象单测无法暴露 DOMRect 的原型 getter；CSS 设置小地图外框不能替代库组件内部 SVG 尺寸。手机选中位置要按抽屉未遮挡的画布计算，初次 loading 与后续大批 live loading 不能共用新增计数重置逻辑。

## 2026-09-06 — 持久 PATH 必须作为安装交付的一部分

- 用户反馈：每次新开终端仍需手动 source Cargo 环境，不符合直接启动的安装体验；授权实际配置并更新 Agent 指令。
- 修正原则：用户明确授权后，备份并最小修改对应 shell 启动文件，而非只返回临时命令。README 的一句话安装指令应包含这项授权，避免 Agent 将必要配置留给用户反复处理。
- 后续检查：从不含 Cargo 的初始 PATH 启动新交互式 shell 验证，验收命令中不能先 source；检查幂等性和其他配置保留，备份不放入仓库或输出私密内容。

## 2026-09-06 — 公开仓库移除与取消展示不是同一需求

- 用户纠正：根目录使用指南与实施计划不应公开，要求从历史中移除，而不是仅取消 README 链接。
- 修正原则：按明确指定路径执行；公开历史和标签重写须取得授权，先保留仓库外备份，再使用逐引用远程状态校验，避免覆盖他人新提交。
- 后续检查：验证所有可达历史而非只查 HEAD；本地保留副本应加入精确 ignore。说明旧克隆或托管平台缓存不属于此次 Git 引用更新可直接清除的范围。

## 2026-09-06 — 工具链缺失提示应先排查 PATH

- 用户反馈：按系统提示安装 Cargo 1.75 后，因 v4 锁文件报错；希望 README 覆盖排错且不要让用户阅读无关过程文档。
- 修正原则：先查已有 rustup 和 PATH，再决定是否安装工具链，同时检查 Cargo 与 Rust 版本。用户入口只列安装、使用、版本记录；开发文档保留历史，不将取消链接描述为隐藏或删除。
- 后续检查：区分软件实际未安装、PATH 缺失与版本过旧；不能用修改锁文件或卸载系统依赖绕过，不因清理展示面擅自重写公开历史。

## 2026-09-06 — 安装目录不等于日常工作目录

- 用户反馈：希望安装后直接通过命令启动，不必进入 Navigator 源码文件夹。
- 修正原则：明确 cargo install 安装独立命令，只有首次源码安装需要项目目录；日常启动只依赖安装目录已在 PATH。
- 后续检查：Agent 需验证源码目录之外、新终端中的命令解析；绝对路径调用成功或当前进程临时 PATH 不代表持久安装体验已交付。

## 2026-09-06 — 简化入口不能弱化终端版

- 用户反馈：网页版只是方便阅读，README 应明确用户也可以使用终端版。
- 修正原则：首屏并列终端与网页命令，说明安装一次即可任选；Agent 指令不替用户决定只启动网页。
- 后续检查：安装、选择会话、焦点导航、退出与 Agent 验收均覆盖两种模式，HTTP 地址与令牌限制只归属于网页版。

## 2026-09-06 — 使用者入口应短，Agent 步骤应可执行

- 用户反馈：分发与安装说明太复杂，希望把一句话交给自己的 Agent 就能部署测试。
- 修正原则：README 先回答产品是什么、把哪句话发给 Agent、怎样打开；详细验证命令放链接文档，不把发布工程方案放在使用者的首屏。
- 后续检查：指令要绑定真实源码目录或用户提供的仓库地址，不能编造公开链接；安装完成必须验证 binary、只读 HTTP 与实际启动，缺少会话应解释为空态而非安装失败。

## 2026-09-06 — 执行生命周期不等于任务正确性

- 用户反馈：执行已结束却显示叉，会把中途可恢复的工具失败误读为最终结果错误。
- 修正原则：完成/执行错误/中断与活动错误计数独立；正常完成可同时带 !N 警告。Navigator 不评判结果正确，用户通过最终回复判断。
- 后续检查：先失败后重试、完成后晚到失败工具镜像不能将 completed 改为 failed；中断不充当工具错误，不覆盖 rollback。

## 2026-09-06 — 会话选择入口应服务用户主任务

- 用户反馈：启动直接打开会话不如先选择清楚，子代理列表对日常浏览无用且易混淆。
- 修正原则：默认始终显示主会话 Picker，不因唯一候选跳过选择；解析兼容子代理不等于需要把子代理暴露在默认列表。
- 后续检查：启动、s 返回、r 刷新、--all 均只列 MAIN；UNKNOWN 不猜成 MAIN，显式 --session 保留诊断入口，不自动跳转父会话。

## 2026-09-06 — 导航快捷键应遵循当前焦点

- 用户反馈：宽窄终端切换后，g/G 仅能操作时间线，无法跳转正文首尾。
- 修正原则：与 j/k 一样，g/G 必须按照 Timeline / Viewer 焦点分发；布局宽度只影响展示，不能改变按键语义。
- 后续检查：同一个 App 经历宽 → 窄 → 宽的实际渲染与焦点切换；确认正文首尾跳转不改变所选 Turn，不清除历史新消息提示。
